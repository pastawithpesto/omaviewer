# OmaViewer 0.1.0

Control your Omarchy computer from Android. View windows, use desktop keys, run terminal sessions, and transfer files.

Includes clipboard transfers, saved connections, themes, and adjustable controls.

Requires Omarchy and Android 8 or later. The default connection method uses Tailscale.
